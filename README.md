# Cat-logo-de-Eletr-nicos-frontend
Tema: Catálogo de Eletrônicos. Criei a seção Análise de Produtos com array de 8 produtos, funções com return e parâmetro padrão, e map, filter e reduce. Mostra quantidade, valor total, preço com 10% de desconto, classificação (barato, médio, caro) e só os baratos. Usei querySelector, createElement, textContent, append e classList.add.

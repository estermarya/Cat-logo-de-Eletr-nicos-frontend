# Cat-logo-de-Eletr-nicos-frontend
Tema: Catálogo de Eletrônicos. Criei a seção Análise de Produtos com array de 8 produtos, funções com return e parâmetro padrão, e map, filter e reduce. Mostra quantidade, valor total, preço com 10% de desconto, classificação (barato, médio, caro) e só os baratos. Usei querySelector, createElement, textContent, append e classList.add.


AVALIAÇÃO EM PARES - Avaliadora: Letícia Correia Felix Ferreira
O projeto apresenta uma aplicação satisfatória dos conhecimentos fundamentais de desenvolvimento Front-End. Destaca-se a utilização dos métodos de manipulação de arrays e do DOM, demonstrando compreensão da lógica de programação em JavaScript.
Entretanto, foram identificadas inconsistências na estrutura dos arquivos e na documentação, além de oportunidades de melhoria na organização do código e na implementação de novas funcionalidades.
Conclui-se que é um projeto adequado como exercício de aprendizagem, mas necessita de alguns ajustes para alcançar uma entrega mais completa, organizada e funcional.
Nota: 8/10
